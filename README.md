# ManifestHub V2

Database of game steam manifest and lua, always updated once a week

> **Note**
This repository is a complete fork of SteamAutoCrack/ManifestHub which has been removed by github and modified to have more games.

# How to use

Just use this api to your project

For checking the manifest is available or not
```
https://api.github.com/repos/8782hei-sketch/ManifestHub-V2/branches/{app_id}
```

For downloading the file
```
https://codeload.github.com/8782hei-sketch/ManifestHub-V2/zip/refs/heads/{app_id}
```
